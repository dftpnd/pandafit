# PandaFit

Настольная программа, которая подгоняет видеофайл под ёмкость оптического диска
и записывает его на болванку.

Открываешь файл — видишь все дорожки с их весом. Решаешь, что выбросить, что
пережать, где обрезать титры. Оценка итогового размера пересчитывается на каждом
кадре отрисовки, рядом — ёмкость вставленного диска и объяснение, чем обернётся
каждое решение.

Мотивирующий случай: UHD-ремукс 61.9 ГБ с семью звуковыми дорожками, три из
которых — DTS-HD и TrueHD по ~4.3 ГБ. Целевая болванка BD-R DL 50.05 ГБ. Выброс
лишних дорожек решает задачу без перекодирования видео вообще — но это
неочевидно, пока не увидишь разбивку по потокам.

Полный дизайн: [`docs/superpowers/specs/2026-08-31-pandafit-design.md`](docs/superpowers/specs/2026-08-31-pandafit-design.md).
План реализации на 19 задач: [`docs/superpowers/plans/2026-08-31-pandafit.md`](docs/superpowers/plans/2026-08-31-pandafit.md).

## Архитектура

Workspace из трёх крейтов, зависимости строго в одну сторону:

```
pandafit-app    egui UI, оркестрация, внедрение зависимостей
     |
     v
pandafit-media  адаптеры: ffprobe, ffmpeg, dovi_tool, mkvmerge, growisofs, привод
     |
     v
pandafit-core   домен: ноль I/O, ноль ffmpeg, ноль egui
```

`core` не знает о существовании ffmpeg — весь домен тестируется без запуска
единого процесса. Над решением пользователя (`Plan`) работают три чистые функции:

```rust
fn estimate(&MediaInfo, &Plan) -> SizeBreakdown
fn explain (&MediaInfo, &Plan) -> Vec<Note>
fn compile (&MediaInfo, &Plan) -> Vec<Step>
```

Оценка размера, объяснения и запускаемые команды выводятся из одной структуры и
не могут разойтись.

## Что уже есть

Крейт `pandafit-core`:

- `Estimated<T>` и `Confidence` — значение с интервалом достоверности
  (`Exact` / `Sampled` / `Guessed`), интервал наследуется от худшего слагаемого
- `MediaInfo`, `Track`, `ColorInfo` — доменная модель файла, включая HDR10 и
  Dolby Vision с признаком базового слоя HDR10
- `Plan`, `TrackAction`, `Target`, `TimeRange` — решение пользователя: действие
  на каждую дорожку, диапазон времени, целевая ёмкость и её источник
- реестр кодеков за трейтом `CodecProfile`: добавление кодека — новый тип и одна
  строка регистрации
  - аудио: AC3, E-AC3, Opus, FLAC
  - видео: HEVC NVENC, AV1 NVENC, x265 с сохранением Dolby Vision
- `BitrateProfile` — профиль битрейта по времени и честный расчёт экономии от
  обрезки интегралом под кривой вместо линейной пропорции
- `estimate` — разбивка по дорожкам, накладные MKV и UDF, страховой запас,
  вердикт-светофор `Ok` / `Tight` / `Over`
- `explain` — объяснения уровней `Info` / `Warning` / `Blocker`: downmix 7.1 в
  5.1 для AC3, время энкода x265, неточность реза по ключевым кадрам, запрет на
  перекодирование Dolby Vision Profile 5
- `compile` — команды для ремукса, перекодирования и прожига через `growisofs`

## Что планируется

- `compile` для цепочки с сохранением Dolby Vision: `dovi_tool extract-rpu`,
  подрезка RPU тем же диапазоном, `ffmpeg` + `libx265`, сборка через `mkvmerge`
- крейт `pandafit-media` — адаптеры за узкими трейтами: `MediaProbe` (ffprobe),
  `BitrateProfiler`, `ThumbnailSource`, `JobRunner` с прогрессом и отменой,
  `DiscDevice` (ёмкость болванки через `READ FORMAT CAPACITIES`, прожиг)
- предполётная проверка: наличие бинарников, инициализация NVENC, свободное
  место, доступ к приводу и чистая болванка
- крейт `pandafit-app` — контроллер `Session` и egui-интерфейс: экран настройки
  с таблицей дорожек и панелью бюджета, полоса миниатюр с маркерами обрезки,
  экран выполнения с живым прогнозом итогового размера
- фактическая точка реза по ближайшему ключевому кадру и `job.json` в рабочей
  папке: повторный запуск подхватывает готовый промежуточный поток, а не
  начинает четырёхчасовой энкод заново

Не входит в замысел: сборка ISO-образа, смена контейнера (выход всегда MKV),
автоподбор параметров и пресеты, очередь файлов, встроенный плеер, работа с
BDMV-структурой и ISO как источником.

## Внешние зависимости

| Инструмент | Нужен для |
|---|---|
| ffmpeg 8.0, ffprobe | всё |
| libx265 | режим Dolby Vision |
| hevc_nvenc, av1_nvenc | быстрый перекод на GPU |
| dovi_tool | режим Dolby Vision |
| mkvmerge (mkvtoolnix) | сборка MKV в режиме Dolby Vision |
| growisofs (dvd+rw-tools) | прожиг |
| sg3-utils | чтение ёмкости болванки |
